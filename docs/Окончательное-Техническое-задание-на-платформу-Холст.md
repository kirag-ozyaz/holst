## 🔷 **1. Общее описание**

Платформа «Холст» — это **веб-приложение с бесконечным холстом**, в котором пользователь может:
- Создавать и управлять **задачами** и **подзадачами** (в виде квадратиков, сворачиваемых/разворачиваемых).
- Создавать **свободные заметки** и **привязывать их к задачам**.
- Строить **двунаправленные связи между заметками** и **направленные связи между задачами** (с защитой от зацикливания).
- Визуализировать всю сеть связей в виде **интерактивного графа**.
- Работать с **таблицами**, **изображениями**, **файлами** внутри карточек и заметок.
- Использовать **голосовой ввод**, **поиск**, **экспорт в PDF/Markdown**, **ИИ-генерацию**.
- Вся система работает **локально**, без подключения к интернету при запуске.

## 🔧 **2. Технологический стек**

| Компонент | Технология |
|----------|------------|
| Backend | **FastAPI** (Python 3.10+) |
| База данных | **PostgreSQL** |
| ORM | **SQLAlchemy** |
| Frontend | **Vue.js 3** + **Pinia** |

## 📦 **3. Функциональные требования**

### ✅ **3.1. Холст (Canvas)**
- Бесконечное пространство с масштабированием и панорамированием.
- Поддержка сетки и привязки.
- Адаптивность: десктоп + мобильные устройства.

### ✅ **3.2. Задачи и подзадачи**
- Карточки с иерархией (любая вложенность).
- Подзадачи отображаются как **квадратики**, сворачиваются/разворачиваются.
- Перетаскивание внутри холста, сохранение позиции.

### ✅ **3.3. Заметки**
- Свободные заметки на холсте.
- Привязка заметок к задачам.
- WYSIWYG-редактор с поддержкой текста, таблиц, изображений.

### ✅ **3.4. Связи**
- **Между задачами**: `depends_on`, `blocks`, `follows`, `related_to` — с **контролем зацикливания**.
- **Между заметками**: **двунаправленные связи** (`linked_to`).
- Визуализация линиями на холсте.

### ✅ **3.5. Граф связей**
- Отдельный режим «Граф».
- Отображение всех узлов (задачи, заметки) и рёбер (связи).
- Интерактивность: масштаб, перетаскивание, фильтрация, переход на холст.

### ✅ **3.6. Файлы**
- Загрузка файлов (до 20 МБ) к карточкам/заметкам.
- Хранение в volume (`/data/uploads/...`).
- Просмотр изображений по двойному клику.
- Безопасный доступ через API (не через Nginx напрямую).

### ✅ **3.7. Поиск**
- Единое поле поиска по всему контенту.
- Full-text search через PostgreSQL (`tsvector`).
- Переход к найденному элементу на холсте.

### ✅ **3.8. Экспорт**
- Экспорт заметок и задач в:
  - **Markdown** (сохранение структуры).
  - **PDF** (визуальное соответствие отображению).

### ✅ **3.9. Голосовой ввод**
- Кнопка 🎤 в редакторе.
- Использование **Vosk** для распознавания речи (русский язык).
- Вставка результата в заметку или отправка как ИИ-запрос.

### ✅ **3.10. ИИ-интеграция (опционально)**
- Генерация контента по запросу (текст, таблицы, задачи).
- Сохранение результата как заметки или карточки.

### ✅ **3.11. История изменений**
- Логирование всех действий в `event_log`.
- Поддержка **undo/redo** (Ctrl+Z / Ctrl+Y).
- Просмотр истории по карточке или холсту.

## 📡 **4. API (основные эндпоинты)**

```http
# Холст
GET    /api/canvas

# Задачи
POST   /api/cards
PUT    /api/cards/{id}
DELETE /api/cards/{id}

# Подзадачи — через cards (рекурсивно)

# Связи задач
POST   /api/task-links
DELETE /api/task-links/{id}

# Заметки
POST   /api/notes
PUT    /api/notes/{id}
GET    /api/notes/{id}/export?format=markdown|pdf

# Связи заметок
POST   /api/note-links
DELETE /api/note-links/{id}

# Файлы
POST   /api/cards/{id}/files
GET    /api/files/{id}/download

# Поиск
GET    /api/search?q=...

# Голос
POST   /api/voice/transcribe  → принимает аудио → возвращает текст

# Граф
GET    /api/graph  → возвращает структуру узлов и рёбер

# История
POST   /api/history/undo
POST   /api/history/redo
```

## 🚀 **6. Пошаговый план выполнения работы**
