# Архив документации

Здесь лежат **устаревшие или неактуальные** материалы. Они сохранены для истории и не описывают текущую реализацию.

**Актуальная архитектура и модель данных:** см. [../architecture.md](../architecture.md), [../classes.md](../classes.md), [../entities.md](../entities.md).

**Объём продукта (MVP):** [../TZ-v2.md](../TZ-v2.md) — не переносился в архив.

| Файл / каталог | Почему в архиве |
|----------------|-----------------|
| `Archtecture.md` | Описание слоёв routers/services, WebSocket, voice как ядро — **не совпадает** с монолитным `backend/app/main.py` и фазой 0–1 |
| `DEVELOPMENT_SETUP.md` | Рекомендации про `docker-compose.dev.yml`, prod-окружение — **файлов нет** в репозитории |
| `SETUP_INSTRUCTIONS.md` | Инструкция «как залить на GitHub», не про приложение |
| `Мое-решение-на-платформу-Холст.md` | Ранний черновик решения, дублирует и расходится с кодом |
| `chat-…Kanban-доской.md` | Экспорт чата / старое ТЗ, не техническая документация |
| `diagrams-legacy/` | PlantUML-диаграммы **до** журнала задач, темы, привязки заметок; частично устарели |

Не удаляйте этот каталог без согласования: в нём могут быть полезные формулировки для истории проекта.
